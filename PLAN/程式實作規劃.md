# 《干貝追蝶夢》程式實作規劃

對應企劃：`PLAN/企劃書.md`  
引擎：Unity 2022.3.62f3 + URP 14  
現況：URP 空專案，尚無遊戲腳本、Spine 套件、Input System。

---

## 1. 目標與約束

可玩迴圈：地面移動 → 追上蝴蝶 → 變身 → 飛行探索。

| 約束 | 實作對應 |
|------|----------|
| 2.5D 橫向捲軸 | 角色鎖定 Z；地面走 X；飛行走 X/Y |
| 16:9 固定 | `AspectRatioEnforcer` letterbox |
| 攝影機只水平平移 | Camera 只改 `position.x` |
| 右側才跟隨 | 角色 viewport X 超過閾值才推鏡 |
| 飛行不超出畫面 | 以攝影機視錐把世界座標 clamp 在可見範圍 |
| Spine + Animator | `SkeletonMecanim` + Unity Animator |
| 程式識別名稱全英文 | 腳本、Prefab、Animator 參數皆英文 |

物理用 **3D**（場景是 3D Plane / 3D 模型）。角色用 `CharacterController`，不混用 2D Physics。

---

## 2. 套件與專案設定

| 項目 | 決定 |
|------|------|
| Input | 先用內建 `UnityEngine.Input`（專案 `activeInputHandler: 0`）。包一層 `PlayerInputReader`，之後可換 Input System |
| Spine | 匯入官方 **spine-unity** runtime，角色用 `SkeletonMecanim` |
| URP | 沿用現有 `Assets/Settings` |
| 物理 | 3D `CharacterController` + Trigger collider |
| 時間 | 變身期間可選 `timeScale` 或只鎖輸入；預設不暫停世界，只鎖玩家操作 |

尚未進專案的資源（Spine、樹、粒子）以 Inspector 欄位掛上，腳本不硬編碼路徑。

## 4. 架構

```
PlayerInputReader
        │
        ▼
   PlayerMotor  ←→  SideScrollCamera / ViewportBounds
        │
        ▼
PlayerAnimationDriver (Animator / Spine)
        │
        ▼
PlayerCatchTrigger ──► GameDirector ──► TransformSequence
                              │
                              ├── PlayerMotor.EnterFly()
                              └── ButterflyController.RetreatToPoint()
```

原則：

- `GameDirector` 只編排流程，不寫移動數學。
- `PlayerMotor` 不知道蝴蝶、粒子。
- 動畫只讀 Motor 狀態，不回頭改移動。
- 攝影機只跟隨，不改角色速度。

## 5. 遊戲階段

```csharp
public enum GamePhase
{
    Ground,
    Transforming,
    Flying
}
```

| 階段 | 輸入 | 移動 | 動畫 | 攝影機 |
|------|------|------|------|--------|
| Ground | 左右、Shift、Space | X + 重力跳躍 | idle / walk / run / jump | 右側閾值推鏡 |
| Transforming | 全部忽略 | 凍結 | 維持當下，等特效 | 停在當前 X |
| Flying | WASD / 方向鍵 | X+Y、無重力 | fly | 右側閾值推鏡；角色 clamp 在畫面內 |

單向：`Ground → Transforming → Flying`。不回到地面。

`GameDirector` 對外：

- `GamePhase CurrentPhase`
- `void BeginTransform(PlayerMotor player, ButterflyController butterfly)`
- 事件：`OnPhaseChanged`

變身只觸發一次（`_hasTransformed`）。

### 6-1. Cat_Ganbei

| Component | 用途 |
|-----------|------|
| Transform | 世界位置；Z 鎖定 |
| CharacterController | 地面走、跳、飛行位移 |
| PlayerInputReader | 讀鍵盤 |

| Component | 用途 |

## 7. 腳本規格

### 7-1. `PlayerInputReader`

每幀快照，Motor 不直接碰 `Input`。

```csharp
public readonly struct PlayerInputSnapshot
{
    public Vector2 Move;   // x: A/D/arrows, y: W/S/arrows
    public bool RunHeld;   // LeftShift / RightShift
    public bool JumpPressed; // Space, GetKeyDown
}
```

對照企劃：

| 動作 | 按鍵 |
|------|------|
| Move.x | A / D / Left / Right |
| Move.y | W / S / Up / Down |
| RunHeld | LeftShift, RightShift |
| JumpPressed | Space |

地面階段忽略 `Move.y`。飛行階段忽略 Run / Jump。

### 7-2. `PlayerMotor`

Inspector：

| 欄位 | 預設 | 說明 |
|------|------|------|
| walkSpeed | 3 | 地面走路 |
| runSpeed | 6 | Shift |
| jumpHeight | 1.5 | `v = sqrt(2 * g * h)` |
| gravity | -20 | 比物理預設重，落地乾淨 |
| flySpeed | 4 | 飛行等速 |
| groundedSkin | 0.08 | `isGrounded` 容差 |
| lockedZ | 0 | 2.5D 平面 |

狀態（給動畫，不進 Animator 參數以外的系統）：

```csharp
public bool IsGrounded { get; }
public bool IsMoving { get; }
public bool IsRunning { get; }
public bool IsJumping { get; }
public int FacingSign { get; }  // 1 right, -1 left
public GamePhase Phase { get; }
```

**Ground**

1. `speed = RunHeld && |Move.x| > 0 ? runSpeed : walkSpeed`
2. `velocity.x = Move.x * speed`
3. 落地且 `JumpPressed` → `velocity.y = jumpVelocity`
4. 空中套 gravity
5. `CharacterController.Move(velocity * dt)`
6. `transform.position.z = lockedZ`
7. `Move.x != 0` 時更新 facing；Spine / localScale.x 轉向

**Transforming**

- `Move(Vector3.zero)`，不改 facing。

**Flying**

1. 關 gravity；`velocity.y` 改由 `Move.y * flySpeed`
2. `velocity.x = Move.x * flySpeed`
3. Move 後用 `ViewportBounds.Clamp(position)` 
4. 仍鎖 Z

公開方法：`EnterTransforming()`、`EnterFlying()`，只准 `GameDirector` 呼叫。

### 7-3. `PlayerAnimationDriver`

讀 Motor，寫 Animator。不播 Spine 名稱字串（交給 Mecanim）。

| Animator 參數 | 型別 | 來源 |
|---------------|------|------|
| Speed | float | `abs(velocity.x)` 地面；飛行可固定 > walk 閾值 |
| IsGrounded | bool | Motor |
| IsRunning | bool | Motor |
| IsFlying | bool | `Phase == Flying` |
| Jump | trigger | 起跳那一幀 |

狀態機：

```
Idle ──Speed > 0.1──► Walk ──IsRunning──► Run
  ▲                    │
  └────Speed ≈ 0───────┘
         │
    Jump / !IsGrounded ──► Jump
         │
    IsFlying ──► Fly（有 Exit Time 的過渡可從任何狀態）
```

過渡建議：

- Idle ↔ Walk ↔ Run：無 Exit Time，快速混合
- Any State → Jump：`Jump` trigger 或 `!IsGrounded`
- Jump → Idle/Walk：`IsGrounded`
- Any State → Fly：`IsFlying`，變身結束後鎖在 Fly

Spine 插槽：`idle` `walk` `run` `jump` `fly` 對應同名 clip。資源未到前可用方塊 + 預設 Animator 跑通邏輯。

### 7-4. `PlayerCatchTrigger`

- 標籤：玩家 `Player`，蝴蝶 `Butterfly`
- `OnTriggerEnter`：對方是 Butterfly 且階段是 Ground → `GameDirector.BeginTransform`
- 變身後 disable 自己，避免重入

### 7-5. `GameDirector` + `TransformSequence`

`BeginTransform` 流程（協程，可調秒數）：

| 步驟 | 行為 | 預設時長 |
|------|------|----------|
| 1 | `CurrentPhase = Transforming`；玩家 `EnterTransforming()` | 0 |
| 2 | 在玩家位置 Play `TransformBurst` | 0 |
| 3 | 等粒子 | 0.8s |
| 4 | `EnterFlying()`；`IsFlying = true` | 0 |
| 5 | `ButterflyController.RetreatToPoint()` | 0 |
| 6 | `CurrentPhase = Flying` | 0 |

蝴蝶撤退與飛行同時開始，不必等蝴蝶走完。

### 7-6. `ButterflyController`

| 欄位 | 說明 |
|------|------|
| retreatTarget | 右側 Transform 或世界座標 |
| retreatSpeed | 水平速度 |
| idleOnly | 預設 true，Animator 不切狀態 |

`RetreatToPoint()`：沿 X 移到目標，Y/Z 不變，到達後停。移動期間仍播 idle。

### 7-7. `AspectRatioEnforcer`

掛在 Camera 或獨立物件：

- 目標 16:9
- 視窗不是 16:9 時加 letterbox（黑邊 Viewport 或兩個 UI Image）
- `OnPreCull` / `OnRectTransformDimensionsChange` 重算

`SideScrollCamera` 的 viewport 計算必須用 letterbox 後的 rect，否則「右邊界」會算到黑邊上。

### 7-8. `SideScrollCamera`

只改 `position.x`。Y 固定（或微幅看地面），Z 固定。

| 欄位 | 預設 | 說明 |
|------|------|------|
| target | 玩家 | |
| rightFollowNormalizedX | 0.72 | 角色螢幕 X 超過此值才推鏡 |
| lookAheadDamping | 0.15 | SmoothDamp |
| neverScrollLeft | true | 符合「右側才跟隨」 |

演算法：

1. 玩家世界座標 → viewport（用 letterbox 後 camera）
2. `viewport.x > rightFollowNormalizedX` → 算一個目標 camera X，讓玩家回到該閾值
3. `cameraX = max(cameraX, targetX)`（不往左）
4. SmoothDamp 到目標

變身期間仍可微跟，避免角色卡住畫面邊緣；不強制鎖死。

### 7-9. `ViewportBounds`

飛行 clamp 用。給 Camera + 角色半徑：

- `MinWorld` / `MaxWorld`：近平面（或角色所在 Z）上，可見矩形
- `Clamp(worldPos, padding)`：X/Y 限制在畫面內；padding 用 CharacterController 半徑與高

地面階段不 clamp 上邊界（跳躍可靠近畫面頂）。飛行階段四邊都 clamp。左邊界建議地面也 clamp，避免走出鏡頭（企劃未寫向左捲動）。

## 8. 輸入 × 階段

| 鍵 | Ground | Transforming | Flying |
|----|--------|--------------|--------|
| A / Left | 左走 | 忽略 | 左飛 |
| D / Right | 右走 | 忽略 | 右飛 |
| W / Up | 忽略 | 忽略 | 上飛 |
| S / Down | 忽略 | 忽略 | 下飛 |
| Shift | 跑步（需有水平輸入） | 忽略 | 忽略 |
| Space | 落地才跳 | 忽略 | 忽略 |

對角飛行：`Move` 正規化後再乘 `flySpeed`，斜向不比較快。

## 9. 碰撞與圖層

| Layer | 用途 |
|-------|------|
| Default | 地形、道具 |
| Player | 貓咪 |
| Butterfly | 蝴蝶 |
| Trigger | 可選；也可用 Tag |

Collision Matrix：

- Player ↔ Default：撞地、被樹擋住（若樹有 collider）
- Player Trigger ↔ Butterfly Trigger：變身
- Butterfly 不與 Default 碰撞（飛在空中）

裝飾用樹若只要看、不要擋路：拿掉 collider 或改 Ignore Raycast。

---

## 10. 攝影機與 2.5D 空間

建議世界約定：

| 軸 | 意義 |
|----|------|
| X | 前進方向（右為正） |
| Y | 高度 |
| Z | 深度；角色 `lockedZ = 0`，道具可微偏 Z 增加層次 |

Camera：看向 `+Z` 或 `-Z`（URP 範本多半看向 +Z，角色 Spine 朝向鏡頭）。角色與蝴蝶同一 `lockedZ`，避免透視大小不一致。

地面：X 向長 Plane。重力 `-Y`。

飛行上下限：以當前 camera frustum 為準，不是世界絕對 Y。鏡頭右移後，可見 Y 範圍若因透視微變，每幀重算 clamp。

## 11. 特效與背景

腳本只負責 Play / Stop，不生成粒子邏輯。

| 特效 | 掛點 | 觸發 |
|------|------|------|
| TransformBurst | 玩家胸口或中心 | 變身步驟 2 |
| AmbientParticles | Backdrop | 場景開始就播 |
| Butterfly glow | 蝴蝶 Prefab 子物件 | 常駐 |

`TransformSequence` 可選：變身時短暫把蝴蝶 parent 到玩家再放開，企劃未要求則不要做。

## 12. 實作順序

每階段結束都要能進 Play Mode 驗收。

### P0 — 專案骨架

- 建資料夾、`DreamChase` 場景
- `AspectRatioEnforcer`（拉非 16:9 視窗看黑邊）
- Ground Plane、方向光、Backdrop 佔位
- 空物件 `Cat_Ganbei`（Capsule）、`Butterfly`（Sphere）

完成標準：16:9 畫面、地面可見、兩個佔位角色站在地上。

### P1 — 地面操作

- `PlayerInputReader`、`PlayerMotor`（僅 Ground）
- CharacterController 走、跑、跳
- 簡易 Animator：Idle / Walk / Run / Jump（Cube 或 Capsule 也可）
- facing 翻轉

完成標準：A/D 走、Shift 跑、Space 跳、落地恢復 Idle。

### P2 — 攝影機

- `SideScrollCamera` + `ViewportBounds`
- 角色靠近畫面右側才右移；不向左捲
- 角色不走出左邊界（可選 clamp）

完成標準：站左邊鏡頭不動；走到右側閾值後鏡頭跟著往右。

### P3 — 蝴蝶與變身

- `ButterflyController`、`PlayerCatchTrigger`、`GameDirector`、`TransformSequence`
- 佔位粒子（預設 Particle System）
- 變身中鎖輸入

完成標準：碰到蝴蝶 → 粒子 → 進入飛行階段（可用 Debug 改速度驗證）。

### P4 — 飛行

- Motor `Flying`：八向、正規化、無重力
- `ViewportBounds.Clamp` 四邊
- Animator `IsFlying` → Fly
- 蝴蝶往右移到定點後停

完成標準：WASD 飛、出不了畫面、蝴蝶停在目標點。

### P5 — Spine 與美術替換

- 匯入 spine-unity、貓咪 / 蝴蝶 skeleton
- `Cat.controller` 接五段動畫
- 蝴蝶只播 idle
- 換 3D 道具、背景、變身粒子

完成標準：與企劃動畫表一致，佔位 mesh 全部換掉。

### P6 — 收斂

- 調速度、跳躍手感、跟隨閾值、變身秒數
- Layer / Tag 清理
- 刪測試用 Debug
- 主場景設為 Build 的第一個 Scene

## 13. Inspector 調參（手感起點）

| 參數 | 起點 | 調整方向 |
|------|------|----------|
| walkSpeed | 3 | 太慢就加 |
| runSpeed | 6 | 約 walk 的 2 倍 |

## 15. 風險與暫代

| 風險 | 作法 |
|------|------|
| Spine 未到 | P1–P4 用 Primitive + Animator；Driver 只寫參數，不依賴 Skeleton 型別 |
| spine-unity 與 URP 材質 | 用官方 URP shader；角色加獨立 Sorting / 微調 Z |
| CharacterController 與 Trigger | 觸發用額外 Trigger collider，不要只靠 CC |
| 透視造成上下可見範圍隨 X 變化 | clamp 每幀用玩家當前 Z 算 frustum |
| 變身連觸 | flag + disable trigger |
| 視窗拖曳破壞 16:9 | Enforcer 每幀或 OnRect 重算；Camera 邏輯用同一 rect |

不在本版範圍：UI 選單、音效系統、存檔、移動平台、敵人、多關卡。需要時另開規劃。
